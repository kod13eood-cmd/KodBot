## Short description

KodBot is an open-source, local-first AI agent workspace. Every bot is a real
agent with its own model, memory, computer, apps, role, and body. Talk to them
like contacts. Watch them work. Approve what matters.

## Homepage sections

### 1. A team, not a chat box

Every bot is a contact with a name, role, voice, body shape, memory, and model.
Some research. Some build. Some watch operations. You decide who is on the team.

### 2. Bring your own brain

KodBot runs on the agent CLIs you already use — Claude, Codex, Grok, and
OpenCode — with your existing logins and subscriptions. Pick a model per bot,
or let Auto model route each task to the strongest or fastest option.

### 3. Agents with hands

Give a bot a cloud Linux desktop, your own machine, or a shared room computer.
It can browse, run commands, edit files, and show you the screen while it works.
Risky actions become approval cards: Allow, Deny, or answer.

### 4. Memory that belongs to you

Each bot has a private workspace and plain-markdown memory. Import context from
ChatGPT or Claude in a few clicks. Read and edit everything the bot believes.

### 5. Artifacts, not walls of text

Ask for a dashboard, checklist, or report and the bot builds a private page you
can open, copy, or share. Ask to compare products and get cards with images,
prices, stores, ratings, and a merchant link.

### 6. Your apps, connected

Gmail, Slack, GitHub, Notion, Linear, Stripe, Aircall, AgentMail, 1Password,
image and video tools — connect the accounts you already use and every bot can
work with them.

### 7. Every bot has a face

Ten body silhouettes, ten colors, eight roles, and a full expression engine.
Two bots with the same job still look like different teammates.

## Feature bullets for the website

- **Local-first:** transcripts, keys, and events stay in `~/.kodbot` or your own server.
- **Bring your own agents:** Claude, Codex, Grok, and OpenCode.
- **Per-bot model picker:** switch models per bot, mid-conversation.
- **Auto model routing:** strongest model for complex work, fastest for simple asks.
- **A real computer per bot:** cloud Linux, local machine, or shared room computer.
- **Approval cards:** shell commands, edits, and questions stop for a human decision.
- **Rooms:** several bots in one conversation with a shared bulletin.
- **Tasks and branches:** separate workstreams and a transcript you can rewind.
- **Pages:** private HTML dashboards, checklists, and reports.
- **Memory import:** bring context from another assistant.
- **Shopping cards:** real product cards with a merchant link, never a fake checkout.
- **Connected apps:** 500+ integrations through Composio.
- **Remote mode:** point the desktop app at a server that stays on 24/7.
- **Voice:** spoken replies and call-style conversations with your ElevenLabs key.
- **Shortcut sheet:** `Cmd/Ctrl+/` for every app-wide command.

## Website FAQ

**Do I need new AI subscriptions?**  
No. KodBot runs on the Claude, Codex, Grok, or OpenCode CLI you already use.
You can add other providers if you want them.

**Where does my data live?**  
On your machine in `~/.kodbot`, or on a KodBot server you control. There is no
KodBot cloud account in the middle.

**Are the Grok Bot features all included?**  
The native ones are: Pages, memory import, auto model routing, shopping cards,
and the shortcut sheet. Vault, Stripe, calls, bot email, and image/video use
real provider accounts through Connected Apps. iPhone actions need an iOS app.

**Can it buy things for me?**  
It can compare products and open the merchant. Payments need a connected Stripe
account and explicit confirmation. KodBot does not pretend a purchase happened.

**Can it call someone?**  
With a connected Aircall account and number, yes. KodBot asks before dialing.

**Does it work on Linux?**  
Yes — Ubuntu Desktop beta, including the Linux AppImage. macOS and Windows have
signed/installable builds.

## Asset checklist

- Hero: bot roster with visibly different body shapes.
- Close-up: Shape picker with Orb / Hex / Star / Ghost.
- Pages: a generated dashboard in the sandbox preview.
- Shopping cards: three products with price, store, rating, and Buy now.
- Auto model: a short prompt vs. a complex prompt with different routed models.
- Connected Apps → Grok features: Live badges and real Set up buttons.
- Approval card: the human decision moment.

## Claims to avoid

- “KodBot gives your bot its own email address” → say “connect AgentMail or Gmail”.
- “KodBot can buy things for you” → say “compare products and open the merchant”.
- “KodBot can call anyone” → say “with a connected Aircall account and number”.
- “All ten features work out of the box” → native features do; provider-backed
  ones need the user's accounts; iPhone actions are not available yet.
